# 인수인계 (2026-11-25)

> 노트북 세션에서 기획·구현·배포를 마친 뒤 맥미니 `hubsetup` 세션에 넘기는 문서다. 이 문서 하나로 이어서 일할 수 있게 썼다.

## 한 줄 요약

html-hub 의 R1~R3 기능(올리기·열기·목록·검색·삭제·버전·본문 검색·댓글·개인 토큰·MCP 업로드)이 모두 구현되어 `https://survey.eunseong.dev` 에서 실제로 돌고 있다. 남은 일은 전부 사용자 입력이나 시간이 필요한 것들이다.

## 지켜야 할 제약

- 비밀값(구글 클라이언트 시크릿, `SESSION_KEY`, 토큰)은 출력하거나 커밋하지 않는다.
- `pople-project/html-hub` fork 는 개인 레포가 끝날 때까지 sync 하지 않는다. 끝났는지는 사용자가 정한다.
- 직원 명단은 사용자 승인 없이 복사하거나 넣지 않는다.
- 바깥으로 나가는 일(메시지 전송, 터널 재시작, 외부 서비스 설정)은 사용자에게 먼저 확인한다. `cloudflared` 를 재시작하면 같은 터널의 다른 호스트 9개가 몇 초 끊긴다.
- 커밋 작성자는 naver 이메일이다. 회사 메일을 로컬 설정에 넣지 않는다.

- 서버: 맥미니 launchd `dev.eunseong.html-hub`. 재시작은 `launchctl kickstart -k gui/$(id -u)/dev.eunseong.html-hub`. 로그는 `/tmp/html-hub.out.log`, `/tmp/html-hub.err.log`.
- 빌드: `/opt/homebrew/opt/rustup/bin/cargo build --release` (PATH 에 cargo 가 없다). `cargo fmt` 가 없어서 `&&` 로 묶으면 빌드가 건너뛰어진다. 빌드는 따로 돌린다.
- 접속: `https://survey.eunseong.dev` → Cloudflare Tunnel(`macmini-tunnel`) → `127.0.0.1:3000`.
- 구글 OAuth: 프로젝트 `html-hub-515801`(silvercastle1024@gmail.com, 조직 없음), 동의 화면은 외부 + 프로덕션 게시 완료. 스코프는 `openid email`. "확인되지 않은 앱" 경고는 나타나지 않았다.
- 직원 명단(DB): `eunseong@greenery.im`(전은성, member) 한 명뿐이다. API 토큰은 활성 0개.

## 구현된 것

| 영역 | 내용 |
|---|---|
| 로그인 | 구글 OIDC, 직원 명단에 있는 계정만 입장. 명단에 없으면 403 + 서버 로그 `명단에 없는 로그인 시도: {email}` |
| R1 | 업로드(10MB), 열기, 목록, 제목·올린이 검색, 프로젝트 필터(자유 입력 + 제안), 삭제(화면에서만 숨김) |
| R2 | 새 버전 교체, 이력, 되돌리기(새 버전으로 추가), 개인 토큰 + `POST /api/upload` |
| R3 | 본문 검색(현재 버전만, `instr`), 댓글(쓴 사람·관리자만 삭제, 숨김 처리) |
| 격리 | 문서는 같은 주소에서 `CSP: sandbox allow-scripts` 로 서빙. 쿠키·localStorage·앱 POST 차단을 실서버에서 확인 |
| MCP | `scripts/mcp_upload.py` (stdio, 도구 `upload_html`) |

정책과 가정의 근거는 `docs/02-해법설계/02-정책서.md`, 인프라는 `docs/02-해법설계/04-인프라.md`, 요구사항과 구현 결과는 `docs/03-명세/01-PRD-R1.md` 에 있다.

## 앞으로 할 일 (전부 사용자 입력이나 시간이 필요하다)

1. **백업 보낼 곳 정하기.** 지금 복사본은 같은 디스크라 디스크 고장은 막지 못한다. 대상이 정해지면 `BACKUP_REMOTE`(rsync 대상)를 launchd 작업에 넣는다.
2. **R2 저장소 교체.** 사용자가 Cloudflare 에서 버킷과 API 토큰을 만들어 주면 `src/docs.rs` 의 `put_file`/`read_file` 두 곳을 R2 로 바꾼다. 그때까지 문서는 맥미니 디스크(`FILES_DIR`)와 같은 디스크 백업에만 있다.
3. **전체 직원 명단 넣기.** 사용자가 "기능을 만든 뒤"로 미뤘고 기능은 끝났다. 워크스페이스 export JSON 을 받으면 맥미니에서 `html-hub import-users <json>` 으로 넣는다. 부서는 사용자가 DB 에서 직접 지정한다. 넣기 전에 사용자 승인을 받는다.
4. **MCP 서버를 Claude Code 에 등록.** 사용자가 `/tokens` 에서 토큰을 발급한 뒤 직접 실행한다.
   ```
   claude mcp add html-hub -e HTML_HUB_URL=https://survey.eunseong.dev -e HTML_HUB_TOKEN=<토큰> -- python3 /Users/jeon-eunseong/eunseong-project/html-hub/scripts/mcp_upload.py
   ```
   파이썬 기본 User-Agent 는 Cloudflare 가 1010 으로 막는다. 스크립트는 `html-hub-mcp/0.1` 을 쓴다.
5. **03:30 백업이 실제로 돌았는지 확인.** `/tmp/html-hub-backup.log` 와 `~/backups/html-hub/db` 를 본다. 아직 자동 실행 결과는 못 봤다(수동 시험은 성공).
6. **처음 403 원인.** 등록된 계정이 처음 한 번 403 을 받았고 끝내 원인을 못 찾았다. DB 행은 active 였고 이후 로그인은 모두 성공했다. 지금은 거부 시 로그가 남으니 재현되면 로그를 먼저 본다.

## 알려진 한계 (만들지 않은 것)

- 로그인 상태 쿠키(oauth state)가 10분 만료라 구글 비밀번호 입력이 길면 "로그인 세션이 만료되었습니다"가 뜬다. 늘릴지는 미정.
- 관리자 화면(숨긴 문서 살리기 `/admin/hidden` 만 있다), 토큰 강제 폐기, 토큰으로 교체·삭제하는 API.
- 문서 수천 건 규모의 검색(그때는 FTS5 trigram 으로 바꾼다), 검색 결과 발췌, 댓글 수정·알림.
- 주소는 임시로 개인 도메인(`eunseong.dev`)이다. 회사 주소로 옮길 때는 구글 리디렉션 URI 와 `BASE_URL` 만 바꾸면 된다.

## 남아 있는 잔여물

- 레포의 추적되지 않는 `.omc/` 폴더(커밋하지 않았다).
- 사용자 Slack DM 에 보낸 시험 메시지 한 건(지우지 않았다).

## 작업 방식 메모

- 문서(`docs/`)는 블로그 「웹 서비스 개발 단계」 순서를 따른다. 결정은 **정함**(사용자) / **가정**(임시) / **미정** 으로 구분해서 적는다.
- 사용자에게 답이 필요하면 `AskUserQuestion` 으로 묻는다. 텍스트 질문으로 턴을 끝내지 않는다.
- 브라우저 시험은 `ego-browser` 로 한다. evaluate 는 15초 제한이 있어 큰 업로드는 비동기로 돌리고 `window.__done` 을 폴링한다.
